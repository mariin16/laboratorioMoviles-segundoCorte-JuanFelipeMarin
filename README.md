Aplicación de mensajería - Laboratorio móviles

Esta aplicación es una recreación de una app de mensajes, con secciones como chat y estados, con una Bottom Bar funcional que cambia la pantalla según el clic, y con botones de Like funcionales en la pantalla inicial.


Cómo ejecutar el proyecto:

1. Clonar o descargar los archivos de repositorio
2. En visual studio, elegir el emulador deseado en la parte inferior derecha
3. Compilar el archivo main.dart

Funcionalidades

- En la pantalla de inicio, hay banners de bienvenida, un scroll horizontal de tarjetas y un scroll vertical de posts

- En la pantalla de chats, hay un componente que respresenta cada chat activo, duplicado para poder hacerlo de forma más efectiva

- En el laboratorio, hay un contador que usa setState para poder modificar el texto con los botones
